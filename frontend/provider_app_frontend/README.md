# Provider App Frontend

Provider-side health insurance admin frontend for InsureFlow.

## Stack

- React
- JavaScript
- Vite
- Axios
- React Router

## Setup

1. Open this folder in a terminal:
   `cd frontend/provider_app_frontend`
2. Install packages:
   `npm install`
3. Create an env file from the example:
   `copy .env.example .env`
4. Start the app:
   `npm run dev`

## Required env

`VITE_PROVIDER_API_BASE_URL=http://localhost:8001`

## Current pages

- Provider admin login
- OTP verification
- Dashboard overview
- Company management
- Health plan creation and listing
