# Customer App Frontend

Customer-facing and admin-operations frontend for InsureFlow.

## Stack

- React
- JavaScript
- Vite
- Axios
- React Router

## Setup

1. Open this folder in a terminal:
   `cd frontend/customer_app_frontend`
2. Install packages:
   `npm install`
3. Create env:
   `copy .env.example .env`
4. Start dev server:
   `npm run dev`

## Required env

`VITE_MAIN_API_BASE_URL=http://127.0.0.1:5100`

## Implemented flows

- customer journey start
- customer login OTP
- customer dashboard
- quote selection and payment flow
- admin login OTP
- admin dashboard
- admin policy issuance hub
